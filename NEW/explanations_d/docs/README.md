# Документация по столбцам таблиц (формат D)

Папка `docs/` содержит описание столбцов для каждого упражнения:

| Файл | Таблица | Упражнение |
|------|---------|------------|
| [ex00.md](ex00.md) | ex00_lifecycle_entities.csv | Выделение объектов с жизненным циклом |
| [ex01.md](ex01.md) | ex01_slots_lifecycle.csv | Жизненный цикл слотов |
| [ex02.md](ex02.md) | ex02_entities_lifecycle.csv | Статусные модели сущностей |
| [ex03.md](ex03.md) | ex03_directories_actions.csv | Действия над справочниками |
| [ex04.md](ex04.md) | ex04_slots_crud.csv | CRUD над слотами |
| [ex05.md](ex05.md) | ex05_slots_additional_actions.csv | Детализация действий над слотами |
| [ex06.md](ex06.md) | ex06_access_rights.csv | Права доступа ролей |

Структура описания каждого столбца:
- **Назначение** — за что отвечает
- **Почему нужен** — связь с заданием/UC
- **Примеры** — типичные значения
- **Связь** — связь с другими столбцами
