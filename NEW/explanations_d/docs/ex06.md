# Ex.06 — ex06_access_rights.csv: описание столбцов

## Объект
**Назначение:** Доменный объект, к которому применяются права.  
**Почему нужен:** Ex.06, п.1 — объекты: Клиенты, Сотрудники, Роли, Услуги, Услуги мастера, Слоты.  
**Примеры:** Клиенты, Слоты обслуживания.  
**Связь:** Группирует строки по объекту.

## Роль
**Назначение:** Роль пользователя.  
**Почему нужен:** Ex.06, п.2 — Менеджер, Мастер, Клиент, Администратор.  
**Примеры:** Клиент, Менеджер, Администратор.  
**Связь:** В паре с «Объект» и «Операция CRUD» задаёт право.

## Операция CRUD
**Назначение:** Разрешённая операция.  
**Почему нужен:** Ex.06, п.3 — права по CRUD.  
**Примеры:** CREATE, READ, UPDATE, DELETE.  
**Связь:** Может быть запрещена (см. «Ограничения»).

## Условия доступа
**Назначение:** При каких условиях операция разрешена.  
**Почему нужен:** Ex.06, п.4.  
**Примеры:** «Клиент авторизован», «Нет активных и будущих записей клиента».  
**Связь:** Должны выполняться для доступа.

## Ограничения
**Назначение:** Дополнительные запреты и рамки.  
**Почему нужен:** Ex.06, п.8 — запрет доступа для исключения неопределённостей.  
**Примеры:** «Только собственная карточка», «Удаление выполняет только администратор».  
**Связь:** Уточняет «Условия доступа».

## Требуются уведомления
**Назначение:** Нужно ли уведомление при операции.  
**Почему нужен:** Ex.06, п.6.  
**Примеры:** Да, Нет.  
**Связь:** Спецификация для уведомлений.

## Требуется журналирование
**Назначение:** Нужно ли логирование операции.  
**Почему нужен:** Ex.06, п.7.  
**Примеры:** Да, «Минимально, факт входа».  
**Связь:** Спецификация для аудита.

## Особые заметки
**Назначение:** Дополнительные правила и рекомендации.  
**Почему нужен:** Ex.06, п.9 — удаление только для Администратора и по регламенту.  
**Примеры:** «Удалять только при выполнении условий хранения», «Рекомендовано архивирование вместо удаления».  
**Связь:** Дополняет «Ограничения».
