# Ex.05 — ex05_slots_additional_actions.csv: описание столбцов

## Роль
**Назначение:** Роль или система, выполняющая действие.  
**Почему нужен:** Ex.05 — продолжение таблицы CRUD с учётом ролей.  
**Примеры:** Клиент, Менеджер, Мастер, Система.  
**Связь:** Та же роль может выполнять несколько действий.

## Действие
**Назначение:** Конкретное действие над слотом.  
**Почему нужен:** Ex.05 — детализация действий (п.1–8).  
**Примеры:** «Просмотр списка свободных слотов», «Массовое создание слотов по шаблону».  
**Связь:** Соответствует операциям из Ex.04, но более детально.

## UC
**Назначение:** Use Case, в рамках которого выполняется действие.  
**Почему нужен:** Связь с сценариями.  
**Примеры:** UC02, UC03, —.  
**Связь:** — для системных фоновых операций.

## Форма визуализации
**Назначение:** Как отображается объект пользователю (Ex.05, п.1).  
**Почему нужен:** Задание на UI: список, карточка, форма.  
**Примеры:** «Список слотов», «Карточка слота», «Нет пользовательского интерфейса».  
**Связь:** Определяет тип экрана/компонента.

## Подтверждение пользователя
**Назначение:** Нужен ли шаг подтверждения (Ex.05, п.2).  
**Почему нужен:** Требование README, раздел 2.1.
