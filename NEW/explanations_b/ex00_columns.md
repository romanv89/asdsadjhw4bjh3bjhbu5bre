# Ex.00 — ex00_lifecycle_entities.csv: описание столбцов

## Сущность
**Назначение:** Название доменной сущности системы.  
**Почему нужен:** Явно перечисляет объекты, для которых ведётся жизненный цикл.  
**Примеры:** Клиент, Сотрудник, Слот обслуживания, Отзыв клиента.  
**Связь:** Строка описывает одну сущность; атрибут статуса относится к ней.

## Описание роли в системе
**Назначение:** Краткое описание роли сущности в предметной области.  
**Почему нужен:** Связывает модель с бизнес-контекстом, помогает разработчикам понять назначение.  
**Примеры:** «Физическое лицо, пользующееся услугами барбершопа», «Единичный интервал времени для оказания услуги».  
**Связь:** Дополняет столбец «Сущность».

## Изменяет ли состояние
**Назначение:** Признак того, меняется ли состояние сущности в процессе работы.  
**Почему нужен:** Позволяет отфильтровать сущности, для которых имеет смысл вводить статусную модель (Ex.00, п.1–3).  
**Примеры:** Да.  
**Связь:** Если «Да» — далее заполняются атрибут статуса и его описание.

## Причина ведения жизненного цикла
**Назначение:** Обоснование необходимости отслеживания жизненного цикла.  
**Почему нужен:** Требование Ex.00, п.4 — предоставить обоснование для каждой сущности.  
**Примеры:** «Поведение бронирования и учета зависит от статуса слота», «Не все отзывы должны сразу отображаться публично».  
**Связь:** Объясняет, зачем нужен столбец «Атрибут статуса».

## Атрибут статуса
**Назначение:** Имя поля в модели данных для хранения статуса.  
**Почему нужен:** Ex.00, п.5 — добавить атрибут «Статус» и актуализировать описание. Мост к реализации в БД/коде.  
**Примеры:** status_client, status_slot, status_review.  
**Связь:** Соответствует столбцу «Описание атрибута статуса».

## Описание атрибута статуса
**Назначение:** Человекочитаемое описание допустимых значений статуса.  
**Почему нужен:** Задаёт перечень состояний для дальнейшей проработки в Ex.01, Ex.02.  
**Примеры:** «Фиксирует актуальное состояние клиента: новый, активен, заблокирован, архивирован».  
**Связь:** Детализируется в таблицах жизненного цикла (Ex.01, Ex.02).
