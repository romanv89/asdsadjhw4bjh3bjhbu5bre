# Ex.04 — ex04_slots_crud.csv: описание столбцов

## Роль
**Назначение:** Роль, выполняющая CRUD над слотом.  
**Почему нужен:** Ex.04, п.1 — роли в разрезе действий CRUD.  
**Примеры:** Менеджер, Клиент, Мастер, Администратор.  
**Связь:** Связана с Ex.06 (права доступа).

## Операция CRUD
**Назначение:** Тип операции над слотом.  
**Почему нужен:** Ex.04 — основные действия CRUD.  
**Примеры:** CREATE, READ, UPDATE, DELETE.  
**Связь:** Детализируется в Ex.05.

## UC
**Назначение:** Use Case, в котором описано действие.  
**Почему нужен:** Ex.04, п.4 — UC с соответствующими действиями.  
**Примеры:** UC02, UC03, UC04, —.  
**Связь:** Проверка полноты UC (столбец «Комментарий к полноте UC»).

## Краткое описание действия
**Назначение:** Что именно делает роль.  
**Почему нужен:** Ex.04 — понятное описание для разработчиков.  
**Примеры:** «Создание одного или серии слотов для мастера», «Отмена собственной брони до начала услуги».  
**Связь:** Расширяется в Ex.05.

## Комментарий к полноте UC
**Назначение:** Замечания по наличию/отсутствию действия в UC.  
**Почему нужен:** Ex.04, п.2–3 — проверка и доработка UC.  
**Примеры:** «В UC02 явно описано создание расписания», «Следует дополнить UC03 сценарием переноса брони».  
**Связь:** Чек-лист для доработки сценариев.
