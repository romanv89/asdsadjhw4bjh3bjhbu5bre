# Диаграмма состояний объекта «Слот обслуживания»

## Ex.01 — Жизненный цикл объекта «Слоты обслуживания»

```mermaid
stateDiagram-v2
    [*] --> Свободен: Создание слота (Менеджер)

    Свободен --> Забронирован_клиентом: Бронирование (Клиент/Менеджер)
    Забронирован_клиентом --> Подтвержден: Подтверждение брони (Система)

    Подтвержден --> В_работе: Начало услуги (Мастер)
    Подтвержден --> Отменен_клиентом: Отмена клиентом
    Подтвержден --> Отменен_барбершопом: Отмена барбершопом
    Подтвержден --> Неявка_клиента: Истечение времени без прихода (Система)

    Свободен --> Отменен_барбершопом: Отмена слота из расписания (Менеджер)
    Свободен --> Истек_без_использования: Истечение даты (Система)

    В_работе --> Выполнен: Завершение услуги (Мастер)
    В_работе --> Неявка_клиента: Фиксация неявки (Мастер)

    Выполнен --> Архивирован: Архивирование (Система)

    note right of Свободен
        Условия: мастер с ролью «Мастер»,
        дата в будущем, пересечений нет
    end note

    note right of Подтвержден
        Условие отмены клиентом:
        до времени услуги осталось
        не менее установленного порога
    end note

    note right of В_работе
        Условие: время начала наступило,
        клиент отметился
    end note
```

## Легенда

| Инициатор | Действие |
|-----------|----------|
| Менеджер | Создание слота, отмена слота/брони |
| Клиент | Бронирование, отмена брони |
| Мастер | Начало/завершение услуги, фиксация неявки |
| Система | Подтверждение брони, автосмена статусов, архивирование |
